# 🚗 Car Game in Python

A simple and fun **Car Game built using Python** where the player controls a moving car and avoids obstacles on the road.

This project is created as a beginner-friendly Python game project to practice **game logic, keyboard controls, movement, collision detection, and graphics**.

## 🎮 Features

- 🚗 Player-controlled moving car
- 🛣️ Road-based gameplay
- ⬅️➡️ Left and right car movement
- 🚧 Obstacles/enemy cars
- 💥 Collision detection
- 🏆 Score system
- 🔄 Game restart functionality
- 🎮 Keyboard controls
- ⚡ Simple and smooth gameplay

## 🛠️ Technologies Used

- 🐍 Python
- 🎮 Pygame
